## Enfoque elegido: Taller de confianza

### Design Movement
Editorial modernism aplicado a software de trabajo creativo: contraste tipográfico, estructura asimétrica, color de papel y acentos de tinta.

### Core Principles
1. La interfaz debe traducir complejidad en pasos visibles y verificables.
2. La confirmación humana es una pausa de confianza, no una fricción burocrática.
3. El histórico se siente como un archivo vivo, no como una tabla administrativa.
4. Cada acción importante tiene una consecuencia visual clara y un lenguaje concreto.

### Color Philosophy
El fondo marfil reduce la sensación de panel técnico y recuerda a una mesa de trabajo. El azul tinta identifica las acciones de criterio y decisión; el coral quemado señala movimiento y avance; el verde salvia queda reservado para estados seguros y resultados listos. La paleta busca calidez sin perder precisión.

### Layout Paradigm
Composición asimétrica de dos columnas: una navegación compacta y una superficie de trabajo amplia. El contenido principal se organiza en bandas editoriales con una columna de contexto lateral, evitando el dashboard de tarjetas repetitivas.

### Signature Elements
- Regla vertical de tinta para marcar el paso actual del encargo.
- Etiquetas tipo ficha de archivo con numeración y estados breves.
- Textura sutil de grano y líneas de papel para dar profundidad sin decorar en exceso.

### Interaction Philosophy
La interfaz responde con microcopys que explican qué ocurrirá después. Las acciones de alto impacto muestran antes el espejo de confirmación. Los estados se actualizan con transiciones cortas, discretas y legibles.

### Animation
Las entradas usan opacidad y desplazamiento vertical de 8–12px con 180ms de duración y easing de salida. Las tarjetas de histórico elevan apenas 2px al pasar el cursor. El espejo aparece con una escala inicial de 0.98, nunca desde 0. Las animaciones se desactivan o reducen bajo `prefers-reduced-motion`.

### Typography System
Display: Fraunces, para titulares y frases de intención. UI/body: DM Sans, para lectura, controles y metadatos. Los titulares mezclan peso 600 con interlineado compacto; las etiquetas usan mayúsculas pequeñas y tracking amplio; los párrafos mantienen un ancho de lectura corto.

### Brand Essence
Encargo convierte necesidades expresadas en lenguaje cotidiano en acciones ejecutables para profesionales creativos, con una capa de entendimiento y control que las herramientas aisladas no ofrecen. Personalidad: atento, criterioso, resolutivo.

### Brand Voice
Los titulares son directos y cercanos; las CTA describen el siguiente movimiento; el microcopy reconoce la incertidumbre sin sonar técnico.

Ejemplo 1: “Cuéntame qué necesitas. Yo ordeno el siguiente paso.”

Ejemplo 2: “Esto es lo que entendí. Tú decides si lo ponemos en marcha.”

### Wordmark & Logo
Un símbolo de dos trazos que se encuentran en un pequeño punto coral: representa la conversación que se convierte en encargo. El wordmark usa “Encargo” en Fraunces semibold con una ligadura visual entre la `g` y la `o`; el icono puede vivir solo como sello de navegación.

### Signature Brand Color
Azul tinta `#18324A`, usado como color propio para el criterio, la confianza y las acciones de confirmación.

## Regla de decisión
Ante cualquier duda visual: ¿esta elección hace que el encargo se sienta más claro, verificable y humano, o lo vuelve un panel genérico de software? Si diluye el enfoque, se descarta.

## Style Decisions

- El paso activo se marca siempre con una regla vertical de tinta visible; las líneas horizontales quedan como apoyo estructural.
- Las etiquetas de archivo usan numeración, estados y lenguaje operacional breve para que cada sección se perciba como un expediente vivo.
- La imagen editorial debe sugerir transformación: de idea a acción, no solo funcionar como atmósfera.
- Las garantías del producto se presentan como anotaciones operativas, conectadas visualmente con el flujo de trabajo.
