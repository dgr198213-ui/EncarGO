# Encargo

MVP frontend de Encargo: una capa de traducción conversacional entre necesidades expresadas en lenguaje cotidiano y tareas ejecutables para profesionales creativos.

## Qué incluye

La aplicación implementa el flujo principal del MVP: intake libre, espejo de confirmación, selección de ruta de ejecución simulada, resultado normalizado, histórico de encargos y contexto de negocio editable. La persistencia de esta primera versión es local al navegador mediante estado React; la integración con autenticación, PostgreSQL/Supabase, Stripe y proveedores externos queda preparada como siguiente fase de producto.

## Desarrollo

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```

La dirección visual está documentada en [`ideas.md`](./ideas.md) y sigue el enfoque editorial “Taller de confianza”.
